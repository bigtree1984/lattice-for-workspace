# 費用

Lattice の費用は、ほとんどが **Gemini（AI）の利用量**で決まります。Cloud Run などの土台は、使っていない間ほぼかかりません。
金額は Google Cloud の料金表で変わるため、ここでは「何に・どれだけかかるか」と「歯止め」を書き、実際の金額はコンソールの請求レポートで確かめてください。

## 1. 何に費用がかかるか

| 部品 | 費用が増えるとき | 規模の目安 |
|---|---|---|
| **Gemini**（Vertex AI） | 会話・要約・下書き・組み直しのたびに。入力（読ませた文書・資料・会話の積み重ね）が大きいほど増える | 費用の大部分 |
| Web Grounding for Enterprise | AI が Web を検索したとき（1回ごと） | 検索の回数しだい |
| サンドボックス | AI が計算したとき（使った時間） | 小さい |
| Cloud Run | 台が動いている間（最後の操作から 15 分ほどで 0 台に戻る）。CPU 常時オンなので、動いている間は CPU にも課金 | 小さい。毎日使って月数千円まで |
| Firestore | 会話・状態の読み書き | ごく小さい（無料枠に収まることが多い） |
| Secret Manager・Artifact Registry・Cloud Build・Logging | 保管とビルド | ごく小さい |
| 共有ドライブ | Google Workspace の契約の中 | 追加なし |

## 2. 利用量の実績（試作環境）

1日に使った Gemini のトークン（入力と出力の合計、全員分）。1〜2人が開発・確認で使った日の値です。

| 日 | トークン | 主な使い方 |
|---|---|---|
| 2026-11-17 | 約 54 万 | 会話の確認 |
| 2026-11-19 | 約 146 万 | 組み直して移す処理の測定（5 Facet × 数回） |
| 2026-11-21 | 約 75 万 | 会話・下書きの確認 |
| 2026-11-22 | 約 212 万 | 組み直し・複製の測定 |

試作環境の11月（1〜23日、1〜2人が開発・測定で使った）の請求は、合計 **約 1,600 円**でした（クレジットで相殺される前の金額）。

| サービス | 金額 |
|---|---|
| Vertex AI（Gemini・Web 検索・サンドボックス） | 1,428 円 |
| Cloud Run（CPU 常時オン） | 131 円 |
| App Engine（Firestore の分） | 4 円 |
| Cloud Storage・Artifact Registry・Secret Manager | 0 円 |

費用の9割が Gemini で、土台はほぼかかっていません。
数えている分のトークン（11-17 以降で約 520 万）から見ると、Gemini は **100 万トークンあたり 200〜300 円**くらいです（数え始める前の分も金額に入っているので、おおよその値）。

- 会話が長くなるほど、それまでの積み重ねを毎回読ませるので、1回の返事あたりのトークンが増えます。
- Facet を組み直して中身を移す処理は、Facet 1つにつき10万トークン前後かかります（11-19 の測定から）。いちばん大きな使い方です。

## 3. 歯止め（3段）

| 段 | 何をするか | 設定 |
|---|---|---|
| 1. アプリの1日の上限 | 超えたら会話に理由を出して止める。翌日に戻る | `LATTICE_DAILY_TOKENS_USER`（既定 200万/人）、`LATTICE_DAILY_TOKENS_TOTAL`（既定 1,000万/全体） |
| 2. 上限予算（spend cap） | 月の金額に達したら、そのサービスの課金を止める | コンソールで、サービスごとに作る（Agent Platform・Cloud Run） |
| 3. 予算のアラート | 50%・80%・100% でメール | コンソール |

1 は即座に効き、2 と 3 は請求の集計を待つので数時間遅れます。1 を主な歯止めにし、2 を二重の備えにしています。

## 4. 費用を左右する設定

| 設定 | 費用への影響 | 既定 |
|---|---|---|
| CPU 常時オン | 画面を閉じても裏の作業が止まらない代わりに、台が動いている間の CPU に課金される | オン |
| 最大の台数 | 大きくすると同時の利用に強くなるが、Lattice は 1 台内で順番を守る仕組みのため増やさない | 2 |
| モデル | 速く安いモデルにするほど安くなる | `gemini-3.8-flash` |
| 1日の上限 | 上の 3 | 200万 / 1,000万 |

## 5. 見積もりの仕方

1. 試作環境の請求レポートで、Gemini（Vertex AI）の「100万トークンあたりの実際の単価」を出す（月の金額 ÷ 月のトークン）
2. 会社での使い方を「1日の利用者数 × 1人あたりのトークン」で置く
3. 1 と 2 を掛け、上の 3 の上限が想定に合っているか確かめる
