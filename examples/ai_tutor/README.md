# 見本のデータ: 生成AIの家庭教師（架空）

管理職などに、生成AIの使い方を教える「家庭教師」サービスの価格を考えるための、架空のデータです。
Lattice の Discussion に添付すると、AI がサンドボックスで集計します。

| ファイル | 中身 |
|---|---|
| `survey.csv` | 見込み客のアンケート 300人（役職、業種、使う頻度、困りごと、受けたい形、希望する回数、1回に払える上限、会社の費用で受けられるか、申し込みたい度合い） |
| `cost.xlsx` | 「単価」（講師の報酬、準備の割合、AI の利用料、教材、道具、決済の手数料、集客の費用）と「プラン案」A〜E |
| `competitors.csv` | 競合 6つ（オンライン講座、企業研修、個人コーチング、少人数講座、独学） |

頼み方の例: 「3つの資料から、プラン案ごとの受講者1人あたりの原価と粗利を出して。アンケートの、申し込みたい度合いが4以上の人が払える上限と、競合の1回あたりの価格とも比べて」
